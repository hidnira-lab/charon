# A4 · Reality 密钥、SNI 与四项连接检查

Charon 不会因为 Xray 进程已启动就直接显示 `已连接`。每次首次连接、切换服务器、睡眠唤醒或网络变更时，核心都会按顺序执行四项验证检查。

## 四项验证检查

1. **服务器可达性 (TCP)**: 检查目标服务器地址和端口是否接受 TCP 连接。
2. **Reality 握手**: Xray 使用你的公钥（`pbk`）、Short ID（`sid`）和 `sni` 完成 TLS 1.3 Reality 握手。
3. **出口 IP 核对**: 通过隧道验证流量出口 IP 与你的服务器地址一致。
4. **隧道内 DNS 检查**: 通过隧道向配置的 DNS 解析器（默认为 `1.1.1.1`，或在 `设置 > 网络` 中设置的自定义 DNS）发起测试查询，确保 DNS 请求真正经过隧道。

## 常见 Reality 配置不一致问题

* **公钥 (`pbk`) 不匹配**: 服务器端的 `privateKey` 与客户端的 `pbk` 必须来自同一次 `xray x25519` 输出。
* **SNI 不在 `serverNames` 中**: 客户端填写的 `sni` 必须包含在服务器 `realitySettings.serverNames` 列表中。
* **系统时间偏差**: 如果服务器与本机时钟相差数分钟，TLS 握手可能失败。请确保两端均已开启 NTP 时间同步。
