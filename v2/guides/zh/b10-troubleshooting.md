# B10 · 故障排查与脱敏诊断导出

## 常见错误原因对照

| 错误情况 | 发生原因 | 处理建议 |
| --- | --- | --- |
| `TCP 连接超时或被拒绝` | 服务器未在所配置的端口接受 TCP 连接。 | 检查 VPS 与 Xray 是否正在运行，以及防火墙端口是否放行（[A5](a5-could-not-reach.md)）。 |
| `Reality 握手失败` | 服务器已响应，但 TLS Reality 握手未通过。 | 核对 `pbk`、`sid`、`sni` 以及服务器 NTP 时间同步（[A4](a4-reality-keys-and-sni.md)）。 |
| `出口地址与服务器不符` | 隧道流量的出口 IP 与你的服务器地址不一致。 | 检查服务器出站路由配置后重试。 |
| `DNS 检查未通过` | 第四项验证检查无法通过隧道解析 DNS。 | 在 `设置 > 网络` 中将 DNS 切换为 `默认`（`1.1.1.1`）或检查自定义 DNS 地址。 |
| `Xray 拒绝了此配置` | `xray run -test` 未通过配置校验。 | 编辑服务器配置，或在 `设置 > 更新` 中回滚 Xray 核心版本。 |
| `TUN 网卡或 wintun 启动失败` | Windows 未能创建 `charon0` Wintun 虚拟网卡。 | 在 `设置 > 应用` 中重启 Charon 服务，或使用安装程序修复。 |
| `本地端口被占用` | 其他本地程序占用了 Xray 所需的内部端口。 | 关闭冲突的代理软件后点击 `重试`。 |

## Windows 服务状态页面

* **`Charon 服务未运行`**: 点击 `启动服务`。如果启动失败，请使用安装程序修复。如果服务停止期间无法上网，点击 `打开释放工具` 清除持久化的 WFP 过滤规则（[A7](a7-kill-switch-and-boot.md)）。
* **`Charon 服务需要更新`**: 当界面窗口与后台服务的 IPC 协议版本不兼容时显示。点击 `更新` 或 `从文件更新`。

## 导出脱敏诊断信息 (`IPC8`)

1. 打开 `设置 > 关于 > 导出诊断信息`（或在 `遥测` 页面点击导出链接）。
2. 保存前先在右侧预览内容。服务器地址、UUID、Reality 密钥和 Short ID 均已替换为 `SRV-01`、`SRV-02` 代号，且默认不包含访问日志。
3. 点击 `保存文件…` 将诊断文件保存到你选择的本地目录。Charon 从不自动上传任何诊断数据。
