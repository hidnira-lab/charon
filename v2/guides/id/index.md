# Panduan Charon

Selamat datang di dokumentasi Charon, klien open source pribadi untuk server VLESS dan Reality yang kamu jalankan sendiri.

* **Bahasa**: [English](../en/index.md) · [Bahasa Indonesia](index.md) · [简体中文](../zh/index.md)

## Panduan Gelombang 1 (Wave 1)

* **[A1 · Memulai dan Apa yang Perlu Disiapkan](a1-getting-started.md)**: Empat hal yang perlu disiapkan sebelum koneksi pertama.
* **[A3 · Checklist Setup Server VLESS dan Reality](a3-server-setup.md)**: Cara memeriksa konfigurasi server Xray sebelum mengimpor tautannya ke Charon.
* **[A4 · Kunci Reality, SNI, dan Empat Pemeriksaan Koneksi](a4-reality-keys-and-sni.md)**: Apa yang diperiksa saat `Memverifikasi` dan mengapa Charon menguji DNS lewat tunnel.
* **[A5 · Saat Charon Menampilkan Tidak Dapat Dijangkau](a5-could-not-reach.md)**: Langkah pemeriksaan saat koneksi pertama gagal verifikasi.
* **[A7 · Kill Switch, Perilaku Boot, dan Pelepasan Darurat](a7-kill-switch-and-boot.md)**: Cara kerja filter WFP permanen di Windows, matriks boot, `charon-release.exe`, dan Always-on VPN di Android.
* **[A12 · Izin Android dan Perilaku Latar Belakang](a12-android-permissions.md)**: Mengapa Android meminta izin VPN dan notifikasi, serta penanganan saat izin VPN dicabut atau diambil alih.
* **[B · Pembaruan Bertanda Tangan, File Bundle, dan Obtainium](b-updates-and-obtainium.md)**: Cara kerja verifikasi rilis Ed25519, pembaruan manual dari file `.charonup`, dan pembaruan Android lewat Obtainium.
* **[B10 · Pemecahan Masalah dan Ekspor Diagnostik](b10-troubleshooting.md)**: Daftar alasan kegagalan, layar `Service Charon tidak berjalan`, `Service Charon perlu diperbarui`, dan ekspor diagnostik tanpa rahasia.
